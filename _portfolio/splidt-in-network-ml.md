At the NextGArch Lab, I developed and optimized ensemble machine learning models for network classification directly on PISA (Protocol Independent Switch Architecture) switches. I implemented and benchmarked classification models — One-class SVMs, Random Forest, and Isolation Forest — in Python to analyze packet payload features for malicious vs. benign traffic, establishing baseline accuracy, computational cost, and scalability trade-offs for real-world in-network security applications.

This work, SpliDT, partitions decision trees to enable scalable, stateful ML inference at line rate, and was presented as a talk and poster at TECHCON 2025.
