Through Purdue's Summer Undergraduate Research Fellowship (SURF), I evaluated LLMs for their ability to generate separation logic specifications for static program verification with VeriFast, progressing from baseline prompt engineering to chain-of-thought (CoT), prompt chaining, and few-shot prompting. I categorized VeriFast benchmarks, built tailored input datasets for systematic evaluation across prompting strategies, and designed a qualitative analysis framework to measure output correctness, syntactic validity, and model failure modes.

This work was published at [FORGE 2025](/publications/#2025-06-13-forge2025-verifast-llm), and an extended empirical study appears at [ISSRE 2026](/publications/#2026-06-01-issre-verifast-empirical-study).
