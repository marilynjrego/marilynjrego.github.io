Static verification tools like VeriFast require developers to hand-write formal specifications, which is a major barrier to adoption. This paper evaluates whether GPT-4o can generate fully accurate specifications that VeriFast can verify, using prompt engineering, chain-of-thought (CoT) reasoning, and few-shot prompting. We categorized the VeriFast benchmark suite, built tailored input datasets for testing, and designed a qualitative analysis methodology to assess output quality — offering an early look at how far off-the-shelf LLMs are from generating machine-checkable proofs.
